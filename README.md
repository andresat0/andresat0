I'm interested in quantitative research, especially empirical finance, time-series methods, and numerical approaches to derivatives pricing.

### Research and academic work

- **FOMC announcements and equity variance:** Honors thesis studying S&P 500 implied and subsequent realized variance around monetary-policy announcements, using event studies, principal component analysis, and controlled regressions.
- **Monte Carlo option pricing:** European-call simulation under geometric Brownian motion and Merton jump diffusion, with analytic benchmarks and sampling-error analysis.
- **U.S. trade-balance forecasting:** Autoregressive modeling and forecast evaluation in Stata.

I'm preparing these academic projects as documented, reproducible repositories. The repositories currently available below include introductory machine-learning and Python coursework.
